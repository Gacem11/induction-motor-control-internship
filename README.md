\# Induction Motor Control Using STM32



\## Overview



This repository contains the software, simulation models, and experimental results developed during my engineering internship at Microtech Lab.



The project focused on the implementation and experimental validation of control strategies for a three-phase induction motor using an STM32 microcontroller and a laboratory three-phase inverter.



\## Main Topics



\- Three-phase PWM generation

\- Sinusoidal PWM

\- Space Vector Modulation

\- Induction motor parameter identification

\- Open-loop V/f scalar control

\- Closed-loop speed control

\- Real-time speed measurement

\- STM32 timer input capture

\- ADC current acquisition and calibration

\- Clarke and Park transformations

\- Indirect Rotor Field-Oriented Control

\- Hysteresis current control

\- MATLAB and PLECS simulation

\- Python-based real-time monitoring



\## Hardware



\- STM32G4RE7

\- Three-phase inverter

\- Three-phase induction motor

\- Current and voltage sensors

\- Infrared speed sensor

\- Laboratory DC power supply

\- Oscilloscope
